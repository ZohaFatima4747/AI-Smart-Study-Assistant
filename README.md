# 🤖 Smart Study Assistant

## 📌 Project Overview

Smart Study Assistant is a web-based application designed to help students learn academic topics using Artificial Intelligence. Users can enter any topic or question and get AI-generated summaries, simple explanations, and MCQs for better understanding.

---

## 🎯 Features

* 🔐 User registration and login system
* 🧠 AI-powered topic explanations
* 📝 Automatic summary generation
* ❓ MCQ generation (for practice)
* 📚 User query history storage
* 🗂️ Delete and manage history
* 💬 Simple chat-style interface

---

## 🛠️ Tech Stack

* Frontend: HTML / CSS / JavaScript (or React if used)
* Backend: Node.js / Express (or your backend)
* Database: MongoDB
* AI Integration: OpenAI API / AI model (if used)

---

## 📂 Project Structure

* Frontend UI for user interaction
* Backend API for handling requests
* Database for storing users and history
* AI service for generating responses

---

## 🚀 How It Works

1. User logs in or registers
2. Enters a topic or question
3. System sends request to AI
4. AI returns:

   * Summary
   * Simple explanation
   * MCQs
5. Data is stored in user history

---

## 🎓 Purpose

This project was built as a final-year academic project to demonstrate how AI can be used in education to simplify learning and improve student understanding.
