About the Project

Built for Students,
Powered by AI

Smart Study Assistant is a web-based academic tool that helps students understand any topic using Generative AI. Whether you need a quick summary before an exam, a clear explanation of a difficult concept, or a set of practice questions — this tool has you covered.

Built with Node.js, MongoDB, and Google Gemini, the project demonstrates how modern AI APIs can be integrated into a clean, modular web application that runs entirely on your local machine.

HTML / CSS / JS Node.js MongoDB Google Gemini JWT Auth
